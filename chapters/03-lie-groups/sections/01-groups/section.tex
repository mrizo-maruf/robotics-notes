\section{Groups, manifolds and Lie groups}\label{sec:lie:groups}

Before any calculus, we need names for the two structures that chapters~\ref{ch:pl} and~\ref{ch:rot} used without naming them: transformations that can be chained and undone (a \emph{group}), and constraint surfaces that are curved but locally flat (a \emph{manifold}). A Lie group is an object that is both at once, with the two structures compatible.
